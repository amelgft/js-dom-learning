### attributs manipulation

In the Document Object Model (DOM), various attributes of HTML elements can be manipulated, including but not limited to classes, href, src, id, and more. Here are some common attribute manipulations:



```javascript
document.querySelector("a").attributes;
```

```javascript
document.querySelector("a").getAttribute("href");
```

```javascript
document.querySelector("a").setAttribute("href","https://www.bing.com/");
```
