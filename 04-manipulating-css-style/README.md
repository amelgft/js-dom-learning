

### Key Concepts

- **JavaScript Naming Conventions**: JavaScript uses camel case for naming variables and functions. For example: `querySelector`.
- **Style Changes Using JavaScript**: When modifying styles with JavaScript, ensure that the values are treated as strings.
- **Style Property Syntax**: To change styles using JavaScript, use the CSS property names but adhere to JavaScript's camel case convention. For example:
  - In CSS: `background-color: red;`
  - In JavaScript: `element.style.backgroundColor = "red";`
