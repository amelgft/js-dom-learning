### Key Concepts

In this lesson, we discussed several points:

- **Ways to Add JavaScript to HTML**: There are three ways to add JavaScript into an HTML file:
  - Inline
  - Outline
  - External

### Lessons Learned

- **String Quotation Handling**: In JavaScript, when using double quotes (`"`) inside other double quotes, use single quotes (`'`) inside the double quotes to avoid conflicts.
- **Avoid Inline JavaScript**: It's best practice to avoid using inline JavaScript.
- **Placement of `<script>` Tag**: The placement of the `<script>` tag matters significantly. The best practice is to place the `<script>` tag just before the closing `</body>` tag.
